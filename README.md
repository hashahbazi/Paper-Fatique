# Computational Materials for FMCG Advertising Fatigue Model

This anonymized repository contains the computational implementation accompanying the manuscript:

> A Dual-State Viscoelastic Optimal Control Model for Advertising Fatigue and Budget Allocation in FMCG

## Repository contents

- `advertising_optimal_control.py` — A standalone Python script that evaluates steady-state outcomes for three FMCG brand archetypes: Leader, Challenger, and Niche.

## Requirements

- Python 3.10 or later
- No third-party packages are required; the script uses Python standard-library modules.

## How to run
```bash
python advertising_optimal_control.py
```
